# Information architecture

## Primary navigation

```text
LifeOrbit
├── Dashboard
├── Notes
├── Planner
├── Calendar
├── Subscriptions
├── Challenges
└── Settings / Account
```

## Main user journey

1. Sign in.
2. Land on the dashboard with today's essentials.
3. Capture a quick note or add a task.
4. See scheduled events and upcoming subscriptions.
5. Complete a challenge and see personal progress.
6. Return tomorrow and pick up where you left off.

## Screen design checklist

Every screen should define: default, empty, loading, error and confirmation
states. Navigation must work with keyboard and touch. Do not bury primary
actions inside hover-only controls.

Dashboard panels: upcoming events, open tasks, recent notes, subscription
renewals, challenge progress. Keep the default view restrained.

## Product language

Friendly, calm, short and supportive. Prefer "Add a task" to motivational
pressure. Do not imply challenges measure someone's worth.
