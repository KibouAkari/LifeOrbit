# LifeOrbit — Zentral Hack Project Documentation

LifeOrbit was conceived and built from scratch by a **two-person team** during Zentral Hack. We began by collecting product ideas and possible features in Miro, then organised the functionality, described the individual areas more precisely, divided the work, selected the technology stack and implemented the web application.

This folder records the project's background, planning, architecture, implementation, and technical limitations. It is a factual project reference, not a presentation or submission guide.

## Project overview

LifeOrbit brings together personal tasks, calendar events, notes, subscriptions and challenges in one web application. Account-based storage and optional sharing allow users to manage personal information and collaborate on events and notebooks.

The codebase uses React, TypeScript, Python/FastAPI and MongoDB Atlas, with deployment on Vercel. Its current functionality and known limitations are described in the documents linked above.
