# Code of Conduct

LifeOrbit should be a friendly project for teammates and contributors.

Be respectful, constructive and welcoming. Discuss ideas rather than
attacking people. Respect differences in experience, identity and opinion.
Do not harass, threaten, discriminate, share private information or use
sexualised language or imagery in project spaces.

Maintainers may remove harmful content, close discussions or restrict
participation to protect contributors.

Report concerns privately to the project maintainers via GitHub rather than
publishing sensitive information in an issue. Reports will be considered
confidentially where practical. This policy applies to issues, pull
requests, reviews and project communication.
